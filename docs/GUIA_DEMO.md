# Guía de demo SVAS (sustentación)

Guion de 10 pasos de `docs/03-plan.md`, clic a clic. Duración objetivo: menos de 15 minutos.
**Antes de empezar**: `npm run db:reset` → `npm run build` → `npm start` (con `DEMO_MODE=true` en `apps/api/.env`) → abrir http://localhost:3000. Tener dos ventanas: una normal (cliente/asesor) y una de incógnito (admin).
Usuarios: `admin@svas.demo / Admin123!` · `asesor1@svas.demo / Asesor123!` · `cliente@svas.demo / Cliente123!`.
